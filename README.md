# Sistema de Ciberseguridad
Sistema de gestión de soluciones tecnológicas de ciberseguridad para productos financieros.

# Objetivo
Implementar una estrategia de trabajo colaborativo que permita a los equipos de desarrollo trabajar de manera organizada y segura utilizando GitHub.

# Tecnologías utilizadas
- GitHub
- Git
- Markdown
- Control de versiones
- Herramientas de desarrollo utilizadas en el proyecto

# Formas de instalación
Para obtener el proyecto, se debe clonar el repositorio desde GitHub utilizando Git:
git clone https://github.com/moliimoli/sistema-ciberseguridad.git

Luego, ingresar a la carpeta del proyecto:
cd sistema-ciberseguridad

# Reglas básicas para trabajar con el código
Para mantener el proyecto organizado se consideran las siguientes reglas:

° Realizar cambios relacionados con el objetivo del proyecto.
° Crear commits con mensajes claros que indiquen los cambios realizados.
° Revisar los cambios antes de realizar un commit.
° Evitar modificar archivos que no estén relacionados con la tarea asignada.
° Utilizar ramas para desarrollar nuevas funcionalidades o realizar modificaciones importantes.
° Mantener actualizados los archivos de documentación.
° Revisar los cambios antes de integrarlos a la rama principal.
