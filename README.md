# Sistema de Ciberseguridad
Sistema de gestión de soluciones tecnológicas de ciberseguridad para productos financieros.

## Descripción
Este repositorio corresponde al desarrollo de la actividad evaluativa relacionada con la empresa Seguridad Tecnológica A Tu Alcance.
El proyecto busca organizar el trabajo de los equipos de desarrolladores mediante GitHub, facilitando la colaboración, el control de versiones y la gestión de los archivos del proyecto.

## Objetivo
Implementar una estrategia de trabajo colaborativo que permita a los equipos de desarrollo trabajar de manera organizada y segura utilizando GitHub.

## Herramientas utilizadas
- GitHub
- Git
- Control de versiones
- Trabajo colaborativo
