# Seguridad del sistema
El sistema debe considerar medidas de seguridad para proteger la información relacionada con productos financieros

# Medidas consideradas
- Autenticación de usuarios
- Control de acceso según roles
- Protección de información
- Registro de actividades
- Control de modificaciones

# Control de accesos
El sistema permitirá controlar el acceso de los usuarios según los permisos asignados, evitando que personas no autorizadas puedan acceder a información protegida.
