# Requerimientos del sistema

# Requerimientos funcionales
- Gestión de usuarios
- Control de acceso
- Registro de actividades
- Gestión de información relacionada con productos financieros

# Requerimientos de seguridad
- Autenticación de usuarios
- Control de permisos
- Protección de la información
- Registro de accesos y modificaciones

# Escalabilidad
El sistema debe permitir incorporar nuevos usuarios y funcionalidades a medida que aumenten las necesidades de la organización.

# Requerimiento de seguridad
El sistema debe permitir controlar los permisos de los usuarios para proteger la información y evitar accesos no autorizados.
